# THÉO : La dernière séance

Jeu d'enquête criminelle interactif en français. Explorez le téléphone de votre meilleur ami pour résoudre son meurtre.

## 🎮 Jouer
👉 [**Lancer le jeu**](https://superjaegermaster.github.io/THEO_ColdCase/)

## 📖 Synopsis
17 septembre 2026. Il y a deux jours, Théo a été retrouvé mort près de son studio de yoga.
La police conclut à un meurtre. Personne n'a rien vu. Personne n'a rien entendu.

Théo avait 31 ans. Il était votre meilleur ami.

Ce soir, l'inspectrice Moreau vous tend une pochette plastique. À l'intérieur : le téléphone de Théo.

« Vous le connaissiez mieux que personne. Regardez. »

Dans ce téléphone : ses messages, ses photos, ses secrets. Et peut-être le visage de celle qui l'a tué.

## 🕵️ Gameplay
- Explorez un smartphone virtuel complet (messages, appels, photos, notes, calendrier...)
- Collectez des indices et construisez votre théorie
- Débloquez progressivement les applications et les secrets
- Découvrez la vérité derrière ce meurtre

## 🛠️ Technique
- Fichier unique autonome (HTML/CSS/JS)
- Aucune dépendance, fonctionne 100% hors-ligne
- Sauvegarde automatique (localStorage)
- Responsive : fonctionne sur desktop et mobile
- 100% en français

## 🚀 Déploiement
Ce jeu est déployé automatiquement via GitHub Pages à chaque push sur la branche `main`.
